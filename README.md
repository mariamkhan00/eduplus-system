# 🎓 EduPlus - Smart Substitute System

**EduPlus** is a modern, cloud-based Teacher Substitute & Absentee Management System designed for Schools, Colleges, and Universities. 

## 🚀 Vision
To automate the manual process of finding substitute teachers, ensuring fair workload distribution, and providing detailed analytical reports for educational institutions.

## ✨ Key Features
* **Smart Substitution Engine:** Automatically assigns free teachers based on lowest workload and subject matching.
* **Multi-School Support (SaaS):** Each school gets its own dashboard and database.
* **Live Dashboards & Analytics:** Generate monthly/yearly graphs for teacher absences and substitutions.
* **PWA (Progressive Web App):** Can be installed on mobile phones and works offline.
* **Interactive Tutorials:** Easy onboarding for new institutions.

## 🛠️ Technology Stack
* **Frontend:** HTML5, CSS3, JavaScript (Bootstrap 5)
* **Backend:** Google Apps Script (API)
* **Database:** Google Sheets (for rapid prototyping and cost-efficiency)
* **Hosting:** GitHub Pages (Frontend) & Google Workspace (Backend)
